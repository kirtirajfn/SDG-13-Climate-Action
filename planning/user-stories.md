# User Stories

## US-01 — Authentication
As a user, I want to register and log in so that my data is saved.

## US-02 — Transport Input
As a user, I want to input transport data so that travel emissions are tracked.

## US-03 — Energy Input
As a user, I want to input energy usage so that home emissions are tracked.

## US-04 — Food Input
As a user, I want to input food data so that diet emissions are calculated.

## US-05 — Consumption Input
As a user, I want to input consumption data so that shopping emissions are tracked.

## US-06 — Calculate
As a user, I want to calculate my footprint so that I know my daily CO2 impact.

## US-07 — Results
As a user, I want to view a breakdown so that I know where my emissions come from.

## US-08 — History
As a user, I want to view my history so that I can track progress over time.

## US-09 — Eco Tips
As a user, I want to view eco tips so that I can reduce my footprint.

## US-10 — Report
As a user, I want to generate a report so that I can share my progress.
